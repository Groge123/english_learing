# 砚台 · 考研英语作文工坊

把 27 考研英语大 / 小作文模板，变成一套可以**逐句套用、实时预览、智能批改**的本地 Web 工具。

- 大作文：图表 / 图画 / 图画+图表 / 文字，四种第一段 + 通用第二三段
- 小作文：书信 / 通知告示 / 纪要，50 个第二段功能句
- 真题库：2001–2026 英一、2010–2026 英二，共 80+ 道题
- AI 教练：本地模式免费可用；可接入 DeepSeek / OpenAI / Kimi / 智谱 / Ollama
- 所有作文保存在浏览器 localStorage，不上传服务器

## 快速开始

### 方式一：双击 `start.bat`（推荐）

需要安装 **Node.js 18+**。双击后会自动打开浏览器：

```
http://127.0.0.1:3210
```

关闭命令行窗口即停止服务。

### 方式二：命令行

```bash
cd kaoyan-writing-studio
node server.js
```

不想自动打开浏览器：

```bash
node server.js --no-open
```

端口被占用时会自动尝试 3211、3212……也可以在启动前设置 `PORT`。

### 方式三：直接打开 `index.html`

页面本身是纯静态的，双击 `index.html` 也能用。但浏览器会拦截 `/api/chat`，所以**大模型功能不可用**，只能使用本地教练。需要 AI 时请用方式一。

## 怎么用

1. **选真题**：进入「真题库」，按年份 / 英一英二 / 题型筛选，点「开始写」。
2. **逐句套模板**：工作台中间每段 3–4 句。点「换一句」换待选模板，黄色空格填主题词 / 数据 / 好处。
3. **生成初稿**：点右上角「生成初稿」，右侧实时预览。也可以点「直接编辑」自己改。
4. **AI 批改**：检查字数、段落、模板覆盖、衔接词、重复词、语法硬伤，给出预估分和下一步建议。
5. **保存 / 导出**：保存到「我的练习」，或导出 `.txt`。

### 大作文推荐练习顺序

1. 2026 英二（静态柱状图）
2. 2023 英二（动态线状图）
3. 2026 英一（双图表）
4. 2024 英一（图画 + 图表）
5. 2023 英一（单图画）
6. 2020 英一（双图画）
7. 文字作文大纲样题（可在工作台把题型切到「文字作文」）

### 小作文使用原则

- 先判断收信人：决定称呼、要不要自我介绍。
- 第一段只写「寒暄 + 写信目的」，细节留第二段。
- 第二段从「功能句库」按功能挑 3–4 句：时间地点、目的、流程、要求、好处。
- 通知 = 换格式的书信；纪要 = 换格式的书信。

## 接入大模型（可选）

1. 点右上角齿轮 →「AI 设置」。
2. 选服务商，填写 Base URL、模型名、API Key。
3. 保持勾选「通过本地代理请求」，保存。
4. 点「测试连接」。

常用配置：

| 服务商 | Base URL | 模型示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| Ollama | `http://localhost:11434/v1` | `qwen2.5:7b` |

说明：

- API Key 只保存在本机浏览器 localStorage，代理服务器不写日志。
- 代理只监听 `127.0.0.1`，不会暴露到局域网。
- 没有 Key 也能用：审题、生成初稿、评分、润色、模板问答全部走本地引擎。

## 设计说明

- **模板是骨架，不是答案**：每篇至少换 3 处主题词、2 处好处、1 个具体例子。
- **第一段不同，第二三段通用**：图表 / 图画 / 文字只在第一段分叉，这是模板能通用的根本原因。
- **小作文按功能背，不按题型背**：建议信、投诉信、邀请信的第二段核心句高度重合。
- **批改只改最值得改的 2 处**：考前时间有限，不要整篇重写。

## 常见问题

**Q：双击 `index.html` 后 AI 按钮没反应？**
A：浏览器不允许 `file://` 页面请求 `/api/chat`。请用 `start.bat` 启动本地服务。

**Q：保存的作文在哪里？**
A：在浏览器 localStorage。换浏览器、清缓存会丢失，建议定期在「我的练习」里「导出全部」。

**Q：为什么生成的初稿里还有 `______`？**
A：这些是本句需要你填的主题词或数据。黄色空格都可以点开填，填完预览会自动更新。

**Q：英一英二需要分别准备模板吗？**
A：不需要。大纲写作要求相同，模板通用；区别主要在字数（英一 160–200，英二约 150）和重点题型。
